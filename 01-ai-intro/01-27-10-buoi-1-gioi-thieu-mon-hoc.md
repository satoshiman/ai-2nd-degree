## Nội dung chính

Buổi đầu giới thiệu tổng quan môn học. Trọng tâm: **học AI khác học software (phần mềm) như thế nào**.

Thông điệp của thầy: **làm chủ công nghệ, tự build ra các con AI** — không chỉ dừng ở mức dùng tool AI có sẵn.

## Học AI khác học Software ở đâu?

| Khía cạnh | Software truyền thống | AI / Machine Learning |
|---|---|---|
| Bản chất | Viết **logic tường minh** (rules, if-else) — deterministic | Học **từ dữ liệu** — probabilistic, kết quả mang tính xác suất |
| Đầu vào | Input + Code → Output | Input + Data (và đáp án mẫu) → Model → Output |
| Đúng/sai | Đúng hoặc sai rõ ràng, test được 100% | Độ chính xác tương đối, không có model "đúng tuyệt đối" |
| Debug | Tìm lỗi trong code | Lỗi có thể nằm ở **dữ liệu**, ở model, ở cách train — khó khoanh vùng hơn |
| Cải tiến | Sửa code → deploy | Thu thập thêm data → train lại → đánh giá lại (vòng lặp thử nghiệm) |
| Kiến thức nền | Cấu trúc dữ liệu, giải thuật, design pattern | + Toán (xác suất, đại số tuyến tính), thống kê, xử lý dữ liệu |

## Điểm giống / cần có từ nền software

- Kỹ năng lập trình vẫn là nền tảng — AI engineer vẫn là software engineer.
- Kỹ thuật phần mềm (versioning, testing, CI/CD, clean code) vẫn áp dụng, thêm tầng mới: versioning data/model, đánh giá model.
- Làm AI production = software engineering + data + model, không chỉ là train model.

## Các nhánh chính của AI

- **Machine Learning**: deep learning, predictive analytics
- **Natural Language Processing (NLP)**: translation, classification & clustering, information extraction
- **Speech**: speech-to-text, text-to-speech
- **Expert systems** (hệ chuyên gia)
- **Planning, scheduling & optimization**
- **Robotics**
- **Vision**: image recognition, machine vision — *hướng chuyên sâu của thầy Tiến*
